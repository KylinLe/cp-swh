# cp-swh · swh 讲解师的课件仓库

普陀中学摄影社上课平台（https://kylinle.github.io/cp/ ）的配套仓库，
专门存放 **swh** 讲解师的课件，用来分担平台主仓库的存储压力。

## 怎么用

- 把课件直接上传到这个仓库的**根目录**（最外层）即可，上课平台的 swh 空间会自动显示，并在课件右侧标注「讲师仓库」
- 支持的格式：html（在线播放）/ ppt / pptx / pdf / doc / docx（下载）
- 课件只放根目录，子文件夹里的不会被扫描
- 推送后等 1-2 分钟（自动清单生成），打开 swh 空间点「刷新」就能看到

## 说明

- 本仓库与主仓库 kylinle.github.io/cp/ 同属一个账号；开启 GitHub Pages（main 根目录）后课件与平台同域名，下载播放稳定
- files.json 由 GitHub Actions 自动生成，请勿手动修改
- 本仓库公开：平台密码门只挡路人，课件在 GitHub 上本身可见（与主仓库一致）
